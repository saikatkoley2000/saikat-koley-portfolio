# Saikat Koley — Executive Portfolio

Executive portfolio of Saikat Koley, General Manager (Technical Operations) with 20+ years of power sector engineering and commercial leadership across transformer oil, synthetic ester fluids, and immersion cooling for BESS and AI data centres.

## Getting Started Locally

To build the production assets and preview locally:

```bash
npm install
npm run build
```

Then open `index.html` directly in your browser or serve with any static web server (e.g., `npx serve .`).

## Deployment

Deployment is automated via Vercel. Pushing to the `main` branch automatically triggers a production build with asset optimization and caching headers configured in `vercel.json`.
